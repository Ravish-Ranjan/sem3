11. Explain how the request and reply together establish an IP-to-MAC address mapping.
    ```
    The sender broadcasts an ARP request to the entire local network, asking for device with IP address 192.168.1.1. The specific device that owns that IP address processes the request and sends a direct, unicast ARP reply stating the IP address 192.168.1.1, and the physical MAC address is 08:00:27:5e:01:7c. The origisnal sender receives this reply and saves the IP-to-MAC mapping in its local ARP cache so it can successfully deliver future data frames to that physical address.
    ```
