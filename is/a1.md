- The low complexity password (Admin@1234) was not cracked despite containing a common word and predictable number pattern. This indicates that although the password is relatively weak, it was not present in the tested wordlist, and the incremental attack did not discover it within the 10-minute time limit.
- The medium complexity password (R3d-Panda#891) combines uppercase and lowercase letters, numbers, symbols, and multiple words, increasing its search space and making it resistant to both attack methods during the test period.
- The high complexity password (Dares-Viral-Unsheathe-Reversion7-Quarrel-Primal) has a very long length and high entropy. These characteristics make exhaustive searching computationally expensive, preventing it from being cracked within the allotted time.
- The very high complexity password (h1@@C@bTJamgdec2) contains a random combination of uppercase letters, lowercase letters, numbers, and special characters. Such randomness significantly increases the number of possible combinations, making it highly resistant to dictionary and brute-force attacks.

## Report

>

    Authentication and access control are fundamental security mechanisms that help preserve the confidentiality of information within an organization. Authentication verifies the identity of a user before granting access to a system, ensuring that only legitimate users can log in. However authentication alone is not sufficient. Access control determines what authenticated users are allowed to view, modify, or execute based on their roles and permissions. This prevents unauthorized users from accessing sensitive files, modifying critical data, or performing actions beyond their responsibilities. In Linux systems, mechanisms such as file ownership like in chown, permission bits like in chmod, and Access Control Lists like with setfacl provide fine-grained control over who can access resources. Together, authentication and access control reduce the risk of data breaches, insider threats, and accidental disclosure of confidential information.

>

    To strengthen password security, organizations should implement a strong password policy that requires passwords to be at least 14–16 characters long and encourages the use of passphrases or randomly generated passwords instead of predictable words or patterns. Additionally, organizations should enforce multi-factor authentication for all user accounts. Even if a password is compromised through phishing or brute-force attacks, MFA provides an additional verification step, significantly reducing the likelihood of unauthorized access. Regular security awareness training and periodic password audits can further improve the overall security posture of the organization.
